# Project Summary
The project is a premium institutional website for SoulPellegriniTech, a technology consulting firm specializing in digital transformation, artificial intelligence, governance, and cybersecurity. The website enhances client interactions for healthcare executives by effectively showcasing services and successful case studies. It features updated branding, optimized navigation, and improved web performance for an enhanced user experience.

# Project Module Description
The project consists of several functional modules:
- **Home**: Introduction and overview of services.
- **About**: Company mission, vision, values, and timeline.
- **Services**: Detailed descriptions of offered services, including Consulting, AI, Cybersecurity, and Digital Transformation.
- **Advisory**: Information on advisory programs for executives.
- **Cases**: Showcase of successful projects with anonymized testimonials, includes a button for direct navigation to the contact page.
- **Contact**: Contact form integrated with Formspree for email submissions.
- **WhatsApp Button**: A floating button for direct communication with animation and tooltip for user interaction.
- **Branding**: Updated logo used in the Navbar, Footer, and favicon.

# Usage
To set up the project:
1. Install dependencies: `npm install --legacy-peer-deps`
2. Build the project: `npm run build`
3. Run the development server: `npm run dev`

### Deploying to Vercel
1. Ensure that the `.npmrc` file is present in both the project root and `app/frontend/` to manage dependencies.
2. Set the **Root Directory** to `app/frontend` in the Vercel Dashboard under Settings → General.
3. Push changes to GitHub to trigger redeployment.
